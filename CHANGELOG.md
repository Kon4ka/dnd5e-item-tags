# Изменения следующего автоматического релиза

- Удалён нижний блок тегов из предметов; теги остаются в общей сетке стандартных свойств. Отменено скрытие штатных флажков.
- Теги Item Tags скрыты в верхней штатной сетке свойств, чтобы не дублировать отдельный блок. Данные свойств и интеграция сохранены.
- Исправлено открытие редактора тегов: шаблон настроек теперь имеет один корневой элемент, как требует ApplicationV2.
- Убрана отдельная кнопка «Теги» из шапки чарника; теги персонажа открываются через меню с тремя точками.
- Компактная сетка тегов с золотистыми флажками вместо отдельных широких рамок.
- Блок тегов находится непосредственно под стандартными свойствами предмета.
- Прямая кнопка «Настроить теги» для ведущего в блоке и отдельном окне тегов; повторное открытие использует уже открытое окно настроек.
- Уточнено название пункта настроек игры и инструкция доступа к редактору.

- Namespaced native properties и адаптер публичного хука Custom D&D 5e.
